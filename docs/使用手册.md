## 1. 概述

giants-xmlmapping 是一个基于注解的 XML ↔ Java 对象双向映射工具，底层使用 dom4j 完成 XML 读写。

使用流程分为三步：

1. 在 POJO 上声明注解，描述类与 XML 元素、属性、子元素之间的映射关系；
2. 用这些实体类构造一个 `XmlMappingData` 实例（同时会解析出内部的 `XmlMapConfig` 映射配置）；
3. 调用 `XmlMappingData` 的方法加载 XML 或生成 XML。

映射配置在运行时通过反射解析注解生成，无需任何 XML 配置文件。

---

## 2. 核心概念

| 概念 | 类 | 说明 |
| --- | --- | --- |
| 映射入口 | `XmlMappingData` | 对外的核心 API，负责加载、生成 XML 与管理对象。 |
| 映射配置 | `XmlMapConfig` | 由实体类注解解析而来的映射元数据集合，通常无需直接操作。 |
| 数据模块 | `XmlDataModule<T>` | 按实体类型存放解析结果的容器，支持按 ID 或类型检索。 |
| 实体元数据 | `XmlMapEntity` 等 | 每个 `@XmlEntity` 对应的内部映射描述，属于框架内部结构。 |

一个 `XmlMappingData` 内部为每种被加载过的实体类维护一个 `XmlDataModule<T>`。加载 XML 时，根元素对应的实体会被实例化并存入对应模块。

## 3. 注解详解

所有注解位于 `com.giants.xmlmapping.annotation` 包，均为 `RUNTIME` 保留。

### 3.1 @XmlEntity

- **作用目标**：类（TYPE）
- **属性**：`name`（默认 `""`）
- **说明**：标记一个类为可映射实体。`name` 指定对应的 XML 元素名；若为空，则取类名首字母小写作为元素名（例如 `Book` → `book`）。
- 未标注 `@XmlEntity` 的类在构造 `XmlMappingData` / `XmlMapConfig` 时会抛出 `XmlMapUndefinedException`。

```java
@XmlEntity(name = "book")
public class Book { ... }

@XmlEntity   // 元素名默认为 "author"
public class Author { ... }
```

### 3.2 @XmlIdKey

- **作用目标**：字段（FIELD）
- **属性**：`name`（默认 `""`，缺省取字段名）
- **说明**：声明主键字段，用于在 `XmlDataModule` 中按 ID 索引对象。
- **类型限制**：字段类型必须位于 `java.lang` 包下（如 `String`、`Integer`、`Long` 等），否则抛出 `XmlMapAttributeTypeErrorException`。
- 解析时，ID 值优先从同名 XML 属性读取；若属性不存在，则尝试从同名子元素的文本读取。两者都为空时抛出 `XmlDataIdKeyIsEmptyException`。
- 生成 XML 时，ID 字段总是作为元素的属性输出；若值为 `null` 会抛出 `XmlDataIdKeyIsEmptyException`。

```java
@XmlIdKey(name = "id")
private String bookId;
```

### 3.3 @XmlAttribute

- **作用目标**：字段（FIELD）
- **属性**：`name`（默认 `""`，缺省取字段名）
- **说明**：将字段映射为 XML 元素的属性。
- **类型限制**：字段类型必须是基本类型（primitive）或 `java.lang` 包下的类型，否则抛出 `XmlMapAttributeTypeErrorException`。
- **布尔特例**：若字段为 `boolean` 且字段名以 `is` 开头（如 `isActive`），映射名会去掉 `is` 前缀并转换（如 `active`）。

```java
@XmlAttribute
private String title;

@XmlAttribute(name = "price")
private Double bookPrice;

@XmlAttribute
private boolean isActive;   // 映射为属性 active
```

### 3.4 @XmlElement

- **作用目标**：字段（FIELD）
- **说明**：将字段映射为单个嵌套子元素。字段类型必须是另一个标注了 `@XmlEntity` 的类。
- 支持自引用：字段类型与所在类相同时，会复用同一实体映射，可用于树状结构。

```java
@XmlElement
private Author author;

@XmlElement
private Node parent;   // 自引用，允许字段类型等于本类
```

### 3.5 @XmlManyElement

- **作用目标**：字段（FIELD）
- **属性**：`elementClass`（默认 `Object.class`）
- **说明**：将字段映射为一组同名子元素。字段类型必须是 `List` 或 `Set`。
- **元素类型推断**：
  - 若字段声明了泛型（如 `List<Book>`），自动取泛型参数作为元素类型，`elementClass` 可省略；
  - 若未声明泛型，则必须通过 `elementClass` 指定元素类型，否则抛出 `XmlMapUndefinedEntityException`。
- 集合中的每个元素都会以其实体名作为独立子元素输出，**不会**额外生成包裹元素。

```java
@XmlManyElement                       // 从 List<Book> 推断元素类型
private List<Book> books;

@XmlManyElement(elementClass = Book.class)   // 未声明泛型时显式指定
private Set books;
```

## 4. XmlMappingData API

`com.giants.xmlmapping.XmlMappingData` 是框架的核心入口。

### 4.1 构造方法

| 构造方法 | 说明 |
| --- | --- |
| `XmlMappingData(XmlMapConfig config)` | 使用已有映射配置，不加载 XML。 |
| `XmlMappingData(XmlMapConfig config, String... xmlFilePathes)` | 使用已有配置，并从 classpath 路径加载 XML。 |
| `XmlMappingData(XmlMapConfig config, InputStream in)` | 使用已有配置，并从输入流加载 XML。 |
| `XmlMappingData(Class<?>... xmlEntities)` | 由实体类构造映射配置，不加载 XML。 |
| `XmlMappingData(Class<?> entity, InputStream in)` | 由单个实体类构造配置，并从输入流加载。 |
| `XmlMappingData(Class<?>[] entities, String... xmlFilePathes)` | 由多个实体类构造配置，并从 classpath 路径加载。 |
| `XmlMappingData(Class<?>[] entities, InputStream in)` | 由多个实体类构造配置，并从输入流加载。 |

> 提示：只要某个实体（含嵌套子实体）会在 XML 中出现，就应把它包含进实体类列表；框架在解析 `@XmlElement` / `@XmlManyElement` 时会递归加载子实体的映射，但根元素能匹配的实体必须在配置中注册。

### 4.2 加载方法

| 方法 | 说明 |
| --- | --- |
| `void loadXml(InputStream in)` | 从输入流读取 XML，按根元素名匹配实体并解析入库。 |
| `void loadXmls(String... xmlFilePathes)` | 从 classpath 加载资源。使用 `ClassLoader.getResources` 获取，**同名资源会全部加载**（适合合并多个 jar 中的同名配置）。 |
| `void loadObject(Object object)` | 直接把一个已存在的对象放入对应数据模块，常用于生成 XML 前。 |
| `void clearObjects(Class<?> moduleClass)` | 清空指定实体类型的数据模块。 |

加载时根元素名若在配置中找不到对应实体，抛出 `XmlDataNotFindEntityException`。

### 4.3 生成方法

| 方法 | 说明 |
| --- | --- |
| `String buildXmlString(Class<?> moduleClass)` | 取该模块中的（首个）对象生成 XML 字符串。 |
| `void writeXml(Class<?> moduleClass, OutputStream out)` | 生成 XML 并写入输出流。 |
| `void writeXml(Class<?> moduleClass, String outFilePath)` | 生成 XML 并写入文件路径。 |

生成时以该实体为根元素。若对象定义了 `@XmlIdKey` 但值为空，抛出 `XmlDataIdKeyIsEmptyException`。

### 4.4 输出格式

默认输出采用 4 个空格缩进（`OutputFormat("    ")`）。

| 方法 | 说明 |
| --- | --- |
| `void setOutputNewlines(boolean newLines)` | 是否输出换行。 |
| `void setOutputEncoding(String encoding)` | 设置输出编码，如 `UTF-8`。 |

### 4.5 访问数据

| 方法 | 说明 |
| --- | --- |
| `<T> XmlDataModule<T> getDataModule(Class<T> moduleClass)` | 获取指定实体类型的数据模块；若尚未加载过该类型则返回 `null`。 |

## 5. XmlDataModule API

`com.giants.xmlmapping.XmlDataModule<T>` 是按实体类型存放对象的容器。

| 方法 | 说明 |
| --- | --- |
| `T get()` | 返回模块中的第一个对象（常用于根实体或单例场景）。空时返回 `null`。 |
| `T get(Serializable id)` | 按 `@XmlIdKey` 的值检索对象。 |
| `Collection<T> getAll()` | 返回模块中所有对象。 |
| `Boolean isNotEmpty()` | 模块是否包含对象。 |

> 存储规则：定义了 `@XmlIdKey` 的实体以其 ID 值为键存放，可用 `get(id)` 检索；未定义 `@XmlIdKey` 的实体以其 `Class` 为键存放（相当于按类型的单例），此时用 `get()` 取回即可。

---

## 6. 类型转换规则

从 XML 文本转换为字段值时，支持以下目标类型（见 `instance` 方法）：

- `String`
- `Integer` / `int`
- `Boolean` / `boolean`
- `Long` / `long`
- `Short` / `short`
- `Double` / `double`
- `Float` / `float`
- `Byte` / `byte`
- `Class`（按全限定名 `Class.forName` 加载）

不在上述范围内的类型会转换为 `null`。生成 XML 时，属性值统一调用对象的 `toString()` 输出。

集合类型转换（`@XmlManyElement`）：字段声明为 `List` 时实例化为 `ArrayList`，声明为 `Set` 时实例化为 `HashSet`。

## 7. 解析与生成细节

### 7.1 元素与文本

解析子元素时框架按其文本内容区分处理：

- **无文本内容的子元素**：视为嵌套实体（`@XmlElement` 或 `@XmlManyElement`），递归解析。未在实体中定义该子元素则抛出 `XmlDataUndefinedElementException`。
- **有文本内容的子元素**：视为属性值，映射到同名的 `@XmlAttribute` 字段（即属性既可写成 XML 属性，也可写成带文本的子元素）。未定义对应属性则抛出 `XmlDataUndefinedAttributeException`。

解析属性时，若出现未在实体中定义的属性，抛出 `XmlDataUndefinedAttributeException`。

### 7.2 ID Key 的读取

`@XmlIdKey` 字段解析时，先尝试读取同名 XML 属性；属性为空时再尝试读取同名子元素文本。两者皆空则抛出 `XmlDataIdKeyIsEmptyException`。

### 7.3 集合元素输出

`@XmlManyElement` 生成 XML 时，集合中的每个元素直接以元素名作为父元素的子节点输出，不产生额外的包裹标签。例如 `List<Book> books` 会在父元素下直接输出多个 `<book>`。

## 8. 异常体系

框架异常分为三类，均为受检异常。

### 8.1 映射配置异常（构造 `XmlMapConfig` / `XmlMappingData` 时）

包 `com.giants.xmlmapping.config.exception`，基类 `XmlMapException`：

| 异常 | 触发条件 |
| --- | --- |
| `XmlMapUndefinedException` | 传入的类未标注 `@XmlEntity`。 |
| `XmlMapAttributeTypeErrorException` | `@XmlAttribute` / `@XmlIdKey` 字段类型不受支持（非基本类型 / 非 `java.lang`）。 |
| `XmlMapUndefinedEntityException` | `@XmlManyElement` 无泛型且未指定 `elementClass`。 |

### 8.2 XML 解析异常（加载 XML 时）

包 `com.giants.xmlmapping.exception`，基类 `XMLParseException`：

| 异常 | 触发条件 |
| --- | --- |
| `XMLFileParseException` | 读取 XML 文档失败（IO 或 dom4j 解析错误）。 |
| `XMLConfigParseException` | 反射实例化对象或属性赋值失败。 |

### 8.3 XML 数据异常（加载 / 生成时）

包 `com.giants.xmlmapping.exception`，基类 `XmlDataException`：

| 异常 | 触发条件 |
| --- | --- |
| `XmlDataNotFindEntityException` | 根元素名在配置中找不到对应实体。 |
| `XmlDataUndefinedElementException` | XML 中出现未在实体中定义的子元素。 |
| `XmlDataUndefinedAttributeException` | XML 中出现未在实体中定义的属性。 |
| `XmlDataIdKeyIsEmptyException` | `@XmlIdKey` 对应的值为空（解析或生成时）。 |

## 9. 完整示例

### 9.1 实体定义

```java
@XmlEntity(name = "catalog")
public class Catalog {

    @XmlAttribute
    private String version;

    @XmlManyElement(elementClass = Book.class)
    private List<Book> books;

    // getters / setters ...
}

@XmlEntity(name = "book")
public class Book {

    @XmlIdKey(name = "id")
    private String id;

    @XmlAttribute
    private String title;

    @XmlAttribute
    private Double price;

    @XmlElement
    private Author author;

    // getters / setters ...
}

@XmlEntity(name = "author")
public class Author {

    @XmlAttribute
    private String name;

    // getters / setters ...
}
```

### 9.2 XML 文档（catalog.xml）

```xml
<catalog version="1.0">
    <book id="b1" title="Effective Java" price="59.0">
        <author name="Joshua Bloch"/>
    </book>
    <book id="b2" title="Clean Code" price="49.0">
        <author name="Robert C. Martin"/>
    </book>
</catalog>
```

### 9.3 解析

```java
try (InputStream in = getClass().getResourceAsStream("/catalog.xml")) {
    XmlMappingData mappingData = new XmlMappingData(
            new Class<?>[] { Catalog.class, Book.class, Author.class }, in);

    Catalog catalog = mappingData.getDataModule(Catalog.class).get();
    System.out.println("version = " + catalog.getVersion());

    // Book 定义了 @XmlIdKey，可按 ID 检索
    Book b1 = mappingData.getDataModule(Book.class).get("b1");
    System.out.println(b1.getTitle());
}
```

### 9.4 生成

```java
XmlMappingData mappingData = new XmlMappingData(
        Catalog.class, Book.class, Author.class);
mappingData.setOutputEncoding("UTF-8");
mappingData.loadObject(catalog);

String xml = mappingData.buildXmlString(Catalog.class);
System.out.println(xml);

// 或写入文件
mappingData.writeXml(Catalog.class, "/tmp/catalog.xml");
```

## 10. 常见问题

**Q：实体类列表需要包含所有嵌套实体吗？**
A：框架会在解析 `@XmlElement` / `@XmlManyElement` 时递归加载子实体映射，因此嵌套子实体可由父实体带出。但为保证根元素能匹配，建议把参与映射的实体都显式传入构造方法。

**Q：`@XmlIdKey` 字段能用自定义对象类型吗？**
A：不能。ID 字段类型必须位于 `java.lang` 包（如 `String`、`Integer`、`Long`），否则构造配置时抛出 `XmlMapAttributeTypeErrorException`。

**Q：属性一定要写成 XML 属性吗？**
A：不一定。`@XmlAttribute` 既能匹配 XML 属性，也能匹配同名的、带文本内容的子元素。

**Q：`getDataModule` 返回了 `null`？**
A：说明该实体类型尚未被加载过（既没有从 XML 解析出该类型的对象，也没有 `loadObject` 过）。请先加载数据。

**Q：布尔字段 `isXxx` 的映射名是什么？**
A：当字段为 `boolean` 且以 `is` 开头时，映射名会去掉 `is` 前缀（如 `isActive` → `active`）。可用 `@XmlAttribute(name = "...")` 显式指定以避免歧义。
